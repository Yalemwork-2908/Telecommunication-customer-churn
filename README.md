Telecommunications Customer Churn Prediction Using Explainable Machine Learning

 Project Overview

This project uses machine learning to predict customer churn in the telecommunications industry. It helps identify customers who may leave a service provider and understand the factors influencing their decisions.

Objectives

- Analyze customer data.
- Predict customer churn.
- Compare machine learning models.
- Identify important churn factors.

 Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- SHAP
- Gradio

 Models

- Logistic Regression
- Random Forest
- Histogram Gradient Boosting

Project Workflow

1. Data collection and exploration
2. Data preprocessing
3. Model training
4. Model evaluation and comparison
5. Model explainability
6. Model deployment using Gradio

How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Upload the required dataset.
3. Install the required libraries.
4. Run the notebook cells in order.
